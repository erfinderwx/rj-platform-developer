# Changes

## Luchs 1.1.0-preview.1 — 2026-10-11

Import the already public ROS 1 and ROS 2 packages into separate trees, retaining upstream version 1.1.0 and Apache 2.0 attribution. Add working Git acquisition, independent ROS 1 driver documentation, public provenance and the version development manual. B launch and YAML default to simulation; documentation identifies draft LCI limitations requiring firmware and physical acceptance.

Add automated Linux SDK and ROS checks. Results and outstanding tests are tracked in the manual. This is a development preview; vehicle compatibility is pending.
