## Upstream 1.1.0 — 2026-10-05

Luchs B. One code base for the Luchs family: same topics, frames, services and tools on Luchs A and Luchs B.

- `luchs_sdk`: `Build::kLuchsB` (wheelbase 1.430 m, track 0.970 m, 22 in tyres, ±30°, single / dual Ackermann). LCI v1.0 draft r3 codec: heartbeat 0x5A5 with alive counter and checksum every cycle, live limits 0x5B0 applied before sending, IMU, attitude, chassis state with checksum and counter checks, EPB / EPS / brake, motor temperatures, version and model check; motion converted between the LCI reference point (rear-axle centre) and base_link. Codec for the Luchs B VCU upper interface V2.6 (0x701 / 0x703) with a host-side speed loop, for units before LCI firmware. `SimBusLci` and `SimBusLegacyB` simulators, `make_simulator()`. Host requests: e-stop, park, payload power, speed cap. `luchs_cli --build b --protocol lci|legacy_b`, `drive --sim`. 63 unit tests.
- Kinematics: a speed reduced by a limit keeps the path curvature on Ackermann models (A-FA / A-DA too). `axle_to_wheel_angles()`.
- `luchs_msgs`: `ChassisState` LCI block (operating mode, e-stop source, fault level, RC link, live limits, EPB / EPS / brake, temperatures, model and firmware); `LampCommand` hazard, headlight, horn, beacon; `SetPayloadPower`, `SetSpeedLimit`.
- `luchs_driver`: `build: b`, `protocol.type`, `lci.*`, `legacy_b.*`, `battery.design_capacity`, `imu/data_raw`, services `~/estop`, `~/park`, `~/set_payload_power`, `~/set_speed_limit`, protocol-specific diagnostics. `config/luchs_b.yaml`.
- `luchs_description`: Luchs B URDF (standard / cooling), `display.launch.py config:=b`.
- `luchs_bringup`: `luchs_b.launch.py` (`protocol:=lci|legacy_b`); `setup_can.sh` takes a bit rate. `luchs_teleop`: Luchs B gamepad scaling.
- `dbc`: `luchs_lci_v1.0_draft_r3.dbc` with `check_lci_dbc.py`; `luchs_b_vcu_v2.6.dbc` generated by `gen_dbc_luchs_b_vcu.py`. `docs/protocol_luchs_b.md`.
- Luchs A behaviour unchanged except the curvature-keeping speed limit on A-FA / A-DA.

## 1.0.0 — 2026-10-05

First release.

- `luchs_sdk`: protocol codec for the Luchs A CAN protocol v1.1, SocketCAN transport, steering kinematics for all four builds, chassis client with command / feedback watchdogs, ramps and limits, `SimBus` simulator, `luchs_cli`, Python examples. 31 unit tests.
- `luchs_driver`: ROS 2 node and component; `cmd_vel` / `TwistStamped`, odometry and TF, joint states, chassis and safety state, `BatteryState`, diagnostics, `reset_odometry` and `set_motion_model` services, dry-run mode.
- `luchs_description`: URDF for A-DF, A-FA, A-DA and A-4WS (A-4WS meshes from CAD).
- `luchs_bringup`, `luchs_teleop`, `luchs` metapackage, DBC files, documentation.
- Fixes over the earlier reference driver: host time (0x5A4) is now sent; motor fault words decode all 32 bits; the fault-lamp request is passed through; wheelbase per build (0.594 m); command watchdog with ramp and gear P; feedback watchdog; firmware-dependent details are parameters; ROS-independent SDK.
