# RJ Platform｜RJ 开发平台

这是 RJ 开发平台面向外部开发者的公开入口。平台方向涵盖电驱动底盘、传感器集成和后续系统开发；第一阶段聚焦底盘与传感器二次开发。

**当前阶段：仓库骨架。** 这里还没有可用的 SDK、驱动、协议、运行配置或示例程序。文档中的待补充项不表示产品已支持或已经实测。真实技术内容将在核实版本、授权和公开范围后逐步加入。
